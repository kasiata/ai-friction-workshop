Vocabulary.

Working with the system

Design challenge
What you want to explore or design. The generator does not interpret this goal itself; you translate it into ingredients and rules.
Collection and ingredient
A collection is a list of possible material. Each line is one ingredient. A, B and C are three separate lists.
Selection and probability
The selection model determines how likely each ingredient is. A 25% probability means about one in four draws, not exactly every fourth draw.
Weight
A ratio between probabilities: weight 3 is three times as likely as weight 1. Weight 0 excludes an ingredient. Probabilities are normalised to total 100%.
Keep randomness fixed (seed)
A seed is the hidden starting number of the random generator. The same seed and the same settings produce the same result. On: repeat the draw sequence while changing one setting. Off: use a new draw each time you generate. The same draws can select different items when ingredients or probabilities change.
New draw
Choose a new starting number without changing ingredients or rules. When randomness is fixed, subsequent generations repeat this new draw sequence. A new draw can still happen to produce the same result.
Comparison
Keep generated output as a reference. Change one part and generate again. Fixed randomness helps you investigate that change.
Connection rule
A dependency between collections. For example: if B selects sharing stories, C may only select quiet or welcoming. The remaining probabilities are renormalised.
Proposal template
The sentence that contains the selected ingredients. {A}, {B} and {C} are placeholders filled by the generator.
Inspecting the draws
See which ingredients were selected, their probabilities and whether a connection rule applied. This makes the result traceable.

Relation types in this workshop
Realises links behaviour to a function. Enables links structure to behaviour. Requires constrains a behaviour to one structure. Inhibits excludes a structure for that behaviour. These are teaching labels, not canonical FBS process names or proven causes.
How FBS relations affect generation
The generator selects one item from A, B and C. In an imported FBS grouping, enabled relationships can restrict those choices. Without a specified relationship, choices remain open. If requirements conflict or all chances become zero, an error appears instead of an arbitrary fallback.
Provisional local FBS classification
Local analysis looks for recognisable goal statements, action verbs and component terms. It does not understand every design and can omit or misclassify material. Check the quotes and fill missing roles; ChatGPT can propose a richer interpretation.

Six selection models

Uniform
Every line in the collection has the same probability. Repeating the same text on several lines creates several chances.
Normal (bell curve)
Ingredients near the selected peak are more likely. Width controls how concentrated the probability is around the peak. List order matters.
Exponential
Probability decreases from the start or end of the list. A larger decay makes this preference stronger.
Zipf (long tail)
A few highly ranked ingredients receive much of the probability; the rest remain possible. A larger exponent increases the difference between ranks.
Triangular
Probability decreases linearly on either side of a peak. Outside the selected width the probability is zero.
Custom weights
Give each ingredient a weight in the same order as the list. At least one weight must be greater than zero.
Peak, width and direction
Peak is a position in the list, not a judgement of content. Width controls the spread. Direction chooses which end receives more probability.

Analysing text

Word frequency
How often a word occurs literally. Common function words are skipped. Frequency is not a measure of meaning or importance.
Co-occurrence
Two different content words within five consecutive content words in the same sentence. A pair counts at most once per sentence. We examine the 32 most frequent content words. Co-occurrence does not prove causation.
LLM and ChatGPT
A language model that can propose categories and relationships. This is interpretation, not an established fact. You copy the prompt into ChatGPT yourself and judge its response.
JSON
A structured text format. ChatGPT returns collections, quotes and rules in this format so the workshop can read them.
Source quote
A literal passage that helps you check a suggestion. Finding a quote proves that the text is in the source, not that the interpretation is correct.
Cognitive friction
A moment when you need to pause, interpret or reconsider your approach. The workshop invites you to record these moments on paper.
System map
An overview of source, collections, probabilities, connections and possible outcomes. Click an ingredient to inspect its source quote. Bars show probabilities before connection rules.
Exploration and prediction
A suggestion for trying a direction, not improving the system. First write what you predict. Then compare with the same draws and undo if you wish. AI suggestions come from the pasted ChatGPT response; local explorations are fixed recipes.
Composite ingredient
Two existing ingredients can be added as one new composite ingredient. The system still selects one ingredient per collection; it does not automatically draw two separate qualities at once.
